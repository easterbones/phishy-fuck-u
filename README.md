# Phishy-Fuck-U

Phishy-Fuck-U è un potente bot WhatsApp multi-funzione basato su [whiskeysockets/baileys](https://github.com/WhiskeySockets/Baileys). Progettato per gruppi e chat private, offre automazioni, giochi, strumenti di moderazione, utility, e tanto altro, con un'installazione semplice e una vasta gamma di plugin personalizzabili.

## Caratteristiche principali
- **Gestione gruppi**: anti-link, anti-spam, anti-fake, benvenuto/addio, promozione/demozione admin, ban, kick, mute, avvisi automatici.
- **Giochi**: blackjack, tictactoe, roulette russa, quiz, 8ball, poker, indovinelli, e altri giochi interattivi.
- **Utility**: download da YouTube, TikTok, Instagram, Pinterest, generazione QR, conversione file, sticker, text-to-speech, traduzioni, calcolatrice, ricerca immagini.
- **Moderazione**: filtro bestemmie, anti-porn, anti-privato, anti-temu, anti-voip, anti-elimina, anti-viewonce, anti-admin, anti-trava, anti-link, anti-spam.
- **Funzioni social**: risposte automatiche, messaggi personalizzati, menzioni, audio divertenti, meme, love meter, barzellette, insulti random, e tanto altro.
- **RPG e economia**: dungeon, livelli, XP, inventario, shop, ranking, missioni, portafoglio, banca, famiglia, animali virtuali.
- **AI e immagini**: generazione immagini AI, risposte AI, effetti su immagini, avatar, canva, canvacord.
- **Gestione file**: upload/download Google Drive, cloud, backup, restore, gestione database.

## Installazione

### Prerequisiti
- Node.js **v18.x** (consigliato, evita versioni troppo recenti)
- [Git](https://git-scm.com/)
- [ffmpeg](https://ffmpeg.org/) installato e accessibile da terminale
- Un account WhatsApp attivo

### 1. Clona il repository
```bash
git clone https://github.com/tuo-username/phishy-fuck-u.git
cd phishy-fuck-u
```

### 2. Installa le dipendenze
```bash
npm install
```

### 3. Configura il bot
- Modifica `config.js` per personalizzare le impostazioni (prefisso, owner, messaggi, API key, ecc).

### 4. Avvia il bot
```bash 
node .
```

### 5. Collega WhatsApp
- Alla prima esecuzione, scegli il metodo di login:
  - **1**: tramite codice QR (scansiona con WhatsApp Web)
  - **2**: tramite codice a 8 cifre (accoppia da WhatsApp mobile)
- Segui le istruzioni a schermo per completare la connessione.

### 6. Goditi il bot!
Il bot è ora attivo e pronto all’uso. Invitalo nei gruppi, prova i comandi e personalizza i plugin secondo le tue esigenze.
